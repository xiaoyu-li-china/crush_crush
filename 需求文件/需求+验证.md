## 2. 背景与目标

### 2.1 背景
主线第20关后，玩家需要新的长期追求。新增「萌宠麻将馆」作为副玩法入口，用低开发成本实现大量关卡。参考3300+关小游戏的工业化思路：固定规则模板 + 参数化关卡 + 随机种子 + 自动校验 + AI预生成主题包 + 美术资源复用。

### 2.2 产品目标
1. 首页左下角新增2个入口：萌宠麻将馆、其他游戏玩法入口。
2. 主线第20关后解锁萌宠麻将馆。
3. 玩家通过「三个相同萌宠麻将自动消除」完成关卡。
4. 第1关教学9张，第2关起固定105张，后续所有关卡均为105张。
5. 通关后自动进入下一关，下一关仅更换萌宠主题图片，规则不变。
6. 严格保证每关必定可解。
7. 道具使用免费，金币用于消耗兑换道具或重玩。
8. 中途退出保存进度。

### 2.3 核心循环
首页 → 萌宠麻将馆 → 关卡页 → 开始对局 → 点击麻将入槽 → 三个相同自动消除 → 得星得金币 → 全部消除通关 → 结算 → 下一关换主题 → 继续。

## 5. 功能需求

### 5.1 首页入口
1. 首页左下角增加2个入口。
2. 入口1：萌宠麻将馆。
3. 入口2：其他游戏玩法入口，具体目标页由其他需求定义。
4. 萌宠麻将馆在主线第20关后解锁。
5. 未解锁时显示锁定状态与解锁条件。
6. 点击萌宠麻将馆进入关卡页。

### 5.2 萌宠麻将馆关卡页
页面元素：
- 标题：萌宠麻将馆
- 顶部：金币数量
- 关卡列表：第1关、第2关、第3关、第4关……可滚动
- 每关状态：锁定 / 可挑战 / 已通关
- 星级展示
- 按钮：开始挑战
- 返回首页

规则：
- 通关后解锁下一关。
- 已通关关卡可重玩。
- 无限关模式下，列表显示最近关卡，支持滚动。

### 5.3 对局内玩法
1. 上方显示萌宠麻将牌堆。
2. 第1关为9张，第2关及后续固定105张。
3. 下方显示6个可填充空格槽。
4. 额外1个槽位显示「看视频免费解锁」。
5. 点击上方麻将，麻将进入下方槽位。
6. 槽位中出现3个相同萌宠麻将时，自动消除。
7. 每消除3个相同麻将：
   - 收集1星
   - 获得1枚金币
8. 所有麻将全部匹配消除后，关卡胜利。
9. 倒计时结束未完成，关卡失败。
10. 槽位满且无法三消时，直接判定失败。
11. 关卡内提示：`匹配所有麻将即可赢得关卡`
12. 第一关引导：`点击麻将放入槽位，3个相同自动消除`

### 5.4 倒计时
- 第1关：12分钟。
- 第2关及后续：12分钟。
- 倒计时结束未消除完，失败。
- 中途退出保存进度，再次进入恢复剩余时间、牌堆、槽位状态。

### 5.5 槽位与广告槽
- 普通槽：6个。
- 视频槽：1个，看激励视频后本局解锁为第7槽。
- 槽位满时：直接判定失败，不再提供局内继续操作。
- 失败后可选择重玩，消耗100金币，或返回。

### 5.6 底部道具

| 道具 | 功能 | 消耗方式 |
|---|---|---|
| 移出 | 将槽位中1张麻将移回牌堆或临时区，腾出槽位 | 免费使用 |
| 凑齐 | 自动从牌堆补齐与槽内某张相同的麻将，凑成3个并消除 | 免费使用 |
| 重排 | 随机打乱剩余麻将的位置 | 免费使用 |
| 翻牌 | 翻开背面或未明牌麻将，或揭示1张可点击牌 | 免费使用 |

补充规则：
- 道具使用不消耗金币。
- 道具数量不足时，可看广告或消耗100金币兑换1个道具。
- 每100金币可兑换1个道具，或消耗100金币重玩一次。

### 5.7 金币系统
1. 每消除3个萌宠麻将，获得1枚金币。
2. 金币全局累计。
3. 金币用途：
   - 消耗100金币兑换1个道具。
   - 消耗100金币重玩一次当前关卡。
4. 金币显示在关卡页、对局页、结算页。

### 5.8 结算
胜利结算：
- 获得星级
- 获得金币
- 剩余时间
- 按钮：下一关 / 再玩一次 / 返回麻将馆

失败结算：
- 失败原因：倒计时结束 / 槽位已满
- 按钮：重玩（消耗100金币） / 返回

### 5.9 无限关卡
1. 第1关：教学，9张。
2. 第2关：105张。
3. 第3关：105张，随机主题。
4. 第4关后：105张，规则与第3关相同，仅更换主题图片。
5. 通关后自动进入下一关。
6. 所有关卡麻将数量固定105，规则基本不变。
7. 支持扩展到3000+关。

## 7. 关卡生成系统

### 7.1 核心思路
固定规则模板 + 参数化配置 + 随机种子 + 自动校验 + AI预生成主题包 + 美术资源复用。

### 7.2 关卡模板
```json
{
  "level": 21,
  "timeout": 720,
  "tileCount": 105,
  "slotCount": 6,
  "adSlot": 1,
  "tools": ["移出", "凑齐", "重排", "翻牌"],
  "rewardPerTriple": {
    "star": 1,
    "coin": 1
  },
  "themeId": "corgi_01"
}
```

### 7.3 可变参数
- 关卡号
- 主题包
- 随机种子
- 每种萌宠的具体数量分配，总和105，每种为3的倍数

### 7.4 随机种子
```text
seed = 玩家ID + 关卡号 + 版本号
```
作用：
- 同一玩家同一关每次进入牌局一致。
- 不同关卡牌局不同。
- 不需要为每一关存完整牌局。

### 7.5 生成流程
```text
1. 确定本关麻将总数：第1关9，第2关及后续105。
2. 确定萌宠种类：例如6种、8种、10种。
3. 每种萌宠数量必须是3的倍数，总和为105。
4. 根据种子随机分配每种萌宠数量。
5. 根据种子生成牌堆顺序。
6. 绑定本关主题图片。
7. 执行严格可解性校验。
8. 校验通过后生成关卡配置。
9. 通关后 level + 1，换主题，继续生成。
```

### 7.6 自动校验
- 第2关及后续 tileCount === 105。
- 每种 tileType 数量 % 3 === 0。
- 所有 tileType 数量总和 === 105。
- 主题图片资源存在。
- 严格可解性校验通过。

### 7.7 严格可解性保证
由于槽位满直接失败，必须保证每关必定可解。

实现方式：
1. 逆向生成：先设计一条合法消除顺序。
2. 正向模拟：按该顺序点击，确保槽位最大占用不超过6。
3. 若模拟失败，重新生成或调整牌堆顺序。
4. 最终关卡必须存在至少一条不爆槽的完整消除路径。
5. 玩家乱点仍可能失败，但关卡本身有解。

## 8. AI主题生成系统

### 8.1 AI负责内容
AI预生成：
- 萌宠麻将正面图
- 牌背图
- 背景图
- 音效
- 主题名称
- 关卡文案

AI不直接决定：
- 每种牌数量
- 可解性
- 难度曲线
- 金币掉落
- 槽位压力

### 8.2 主题包结构
```json
{
  "themeId": "corgi_01",
  "name": "柴犬麻将馆",
  "tiles": [
    "corgi_1.png",
    "corgi_2.png",
    "corgi_3.png",
    "corgi_4.png",
    "corgi_5.png",
    "corgi_6.png"
  ],
  "background": "bg_corgi.png",
  "tileBack": "back_corgi.png",
  "sound": "corgi_bgm.mp3"
}
```

### 8.3 预生成流程
```text
1. 确定萌宠主题列表：柴犬、猫咪、兔兔、熊猫、柯基等。
2. 批量AI生成统一风格的萌宠麻将图。
3. 生成牌背、背景、音效。
4. 人工审核或自动审核。
5. 打包成主题包。
6. 上传CDN。
7. 关卡生成器按themeId调用。
```

### 8.4 注意事项
- 风格统一。
- 尺寸统一，例如512x512。
- 透明背景或方形牌面。
- 版权与违规审核。
- 预生成，不实时生成。
- 用seed控制随机，保证可复现。

## 11. 异常与边界

1. 槽位满且无法三消：直接判定失败。
2. 倒计时结束：判定失败。
3. 中途退出：保存进度，再次进入恢复剩余时间和牌局状态。
4. 广告加载失败：提示稍后重试，不扣次数。
5. 金币不足：提示继续游戏或看广告。
6. 主题资源加载失败：降级到默认主题。
7. 关卡生成失败：重新生成或使用备用配置。
8. 可解性校验失败：重新生成牌局。
9. 无限关达到极大值：可循环主题或重置关卡编号。

## 2. 验证目的

验证萌宠麻将馆是否满足以下核心要求：
1. 首页左下角新增2个入口。
2. 主线第20关后解锁萌宠麻将馆。
3. 第1关教学9张，第2关及后续固定105张。
4. 三消规则、星级、金币、道具、槽位、倒计时正确。
5. 道具免费使用，金币消耗兑换。
6. 槽位满直接失败。
7. 中途退出保存进度。
8. 每关严格保证必定可解。
9. AI主题包预生成，不实时生成。
10. 通关后无限进入下一关，仅换主题图片。

## 7. 可解性专项验证说明

### 7.1 验证目标
确保每关生成后，存在至少一条操作路径，在6个普通槽位内完成全部105张麻将消除。

### 7.2 验证方法
1. 使用关卡生成器生成指定关卡。
2. 运行可解性校验工具。
3. 校验工具模拟预设解路径。
4. 记录槽位最大占用数。
5. 要求最大占用≤6。
6. 要求最终全部消除。
7. 抽样覆盖第1关、第2关、第3关、第10关、第50关、第100关、第500关、第1000关、第3000关。

### 7.3 通过标准
- 抽样关卡100%通过可解性校验。
- 任意失败牌局必须被拦截并重新生成。
- 线上不可出现“生成即无解”的关卡。
