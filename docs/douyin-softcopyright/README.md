# 《萌宠粉碎消》软件著作权登记材料

用于向中国版权保护中心申请计算机软件著作权登记，并把证书上传到抖音开放平台（微信侧也可共用同一份证书）。

## 先确认三件事

1. **是否已有软著**：若微信版已登记，且证书软件名称为「萌宠粉碎消」或「萌宠粉碎消游戏软件」、著作权人与抖音开发者主体完全一致，直接上传那份证书即可，不用再办。抖音的限制是「同一软著只能用于抖音平台上的一款在线小游戏」，跨平台（微信 + 抖音）共用没有问题。
2. **软件名称**：统一使用 **全称「萌宠粉碎消游戏软件」、简称「萌宠粉碎消」、版本号 V1.0**。抖音规定小游戏名称须与软著名称一致：全称只可省略「游戏软件」「app」等后缀，简称必须完全一致。不要在名称里加「抖音」「小游戏」等字样，否则去掉后缀后与「萌宠粉碎消」对不上。
3. **AI 使用承诺**：据多家登记代理机构解读，2026-03-15 起启用的新版申请表要求经办人手写承诺「软件系独立开发、未使用 AI 编写代码 / 撰写文档 / 生成申请材料」（以版权中心系统实际页面为准）。本目录中的说明书提纲和功能描述要点由 AI 辅助整理，**只能作为事实核对参考，提交前须由你本人重新撰写**；源代码是否符合承诺要求，需你按实际开发情况如实判断，拿不准请咨询版权中心或代理机构。

```bash
node scripts/generate-softcopyright-source.mjs
```

## 版权中心对鉴别材料的要求

依据《计算机软件著作权登记办法》第十条：

- 程序与文档各提交 **前、后连续 30 页**；不足 60 页的提交全部。
- 程序每页 **不少于 50 行**，文档每页 **不少于 30 行**（含截图的页除外）。
- 每页页眉标注软件名称与版本号（须与申请表完全一致），并标页码。

## 办理顺序

1. 在 [中国版权保护中心](https://www.ccopyright.com.cn/) 完成实名认证（著作权人与经办人）。
2. 按 **01** 填写在线申请表。
3. 按 **02** 撰写说明书并导出 PDF；上传说明书 PDF 与 `04-源程序鉴别材料.pdf`。
4. 打印签章页，按系统要求签字、手写承诺、上传。
5. 取得证书后，按 **03** 在抖音「基础设置 → 资质信息」上传。
