# 抖音开放平台 · 软著资质上传

入口：小游戏后台「基础设置 → 资质信息」，弹窗「计算机软件著作权登记证书」。规则依据 [小游戏资质规范](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/operation1/norms/credential-norms-for-mini-game) 与 [资质篇常见问题](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/guide/contactus/endowments)。

## 平台规则

| 规则 | 对本游戏的要求 |
|------|----------------|
| 名称一致 | 小游戏名「萌宠粉碎消」= 软著全称去掉「游戏软件」后缀，或 = 软著简称（简称须完全一致） |
| 主体一致 | 软著著作权人须与抖音开发者主体名称完全一致；不一致须上传盖鲜章的授权书 |
| 真实性核验 | 平台会到中国版权登记查询服务平台核验，软件名称、登记号、简称、版本号、登记日期、著作权人须与官方记录完全一致 |
| 一证一游戏 | 同一软著只能用于抖音平台上的一款在线小游戏（与微信共用不受限） |
| 修改次数 | 资质材料（软著、自审、版号）每年可修改 2 次；名称随之变动需重新做小游戏备案和 ICP 备案 |

## 上传字段

| 字段 | 填写 |
|------|------|
| 计算机软件著作权登记证书（必填） | 证书原件扫描件或复印件；jpg / png / jpeg / bmp，单张 ≤ 5MB。企业复印件盖公司鲜章，个人复印件须著作权人签名 |
| 授权书（选填） | 仅在著作权人 ≠ 开发者主体时上传 |
| 计算机软件著作权登记号（必填） | 照证书逐字填写，如 `2026SR0000000` 格式；填错会导致资质审核失败 |

## 取得证书后的游戏内配套

自审自查报告第 7 条要求游戏开始画面显著位置展示著作权登记号等信息及《健康游戏忠告》。当前启动页只有「萌宠粉碎消 · 加载中…」，拿到登记号后需要补上。
