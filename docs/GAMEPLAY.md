# 《萌宠粉碎消》玩法文档

> 基于当前代码与配置整理（截至本地 20 关表）。  
> 定位：萌宠主题步数制三消闯关 + 通关限时粉碎加分 · 纯 IAA（广告变现，无内购）。

---

## 1. 一句话与核心循环

滑动交换相邻萌宠，完成关卡目标后进入限时点击粉碎加分；失败可看广告补步，道具与日常奖励也走广告/登录/邀请。

```
大厅选关 → 进关三消 → 通关 / 失败
                │              │
                │              └→ 激励广告复活（+5 步）或重开 / 回大厅
                ▼
         （可选）剩余步数加成 → 限时粉碎 → 结算
                │
                └→（可选）清洁模式 → 下一关 / 重试 / 回大厅
```

| 阶段 | 玩家做什么 |
|------|------------|
| **大厅** | 点马卡龙选关；设置、玩法速查、公告、邀请、游戏圈、分享 |
| **对局** | 滑动交换；用锤子 / 重排 / 加步；完成头顶目标 |
| **通关** | 有剩余步时先自动加成；再限时点格子粉碎加分 |
| **结算** | 看分、选清洁（达标时）、下一关 / 重试 / 回大厅 |
| **失败** | 重开，或反复看广告每次补 5 步继续 |

## 2. 基础三消

### 2.1 萌宠与棋盘

| 种类 | 名称 |
|------|------|
| 红 / 蓝 / 绿 / 黄 / 紫 | 红狐 / 蓝兔 / 绿蛙 / 黄鸡 / 紫猫 |

- 默认盘面约 **6×6～8×8**（关卡配置）。
- 异形盘会挖出 **洞格**（不落子、不填充）：菱形、心形、十字、单环、双环、沙漏、三分缝等。

### 2.2 交换规则

- 仅 **四向相邻** 可交换。
- 合法：交换后出现横/竖 ≥3 同色；或涉及 **超级猫头鹰**；或 **两枚闪光** 互滑；或两特殊块互换。
- 非法交换：**不扣步**，回弹。
- 合法交换：**扣 1 步**。
- 棉花 / 蛋壳 / 藤蔓覆盖格、空格、洞格不可换；`encase` 冰封格上的动物不可滑。

### 2.3 消除与连锁

1. 全盘扫描横/纵连续同色 ≥3 → 消除  
2. 下落压实 → 顶部填充新块  
3. 再扫描，直到无匹配（连锁）  
4. 每清一格 **+10 分**（道具、步数加成、粉碎同口径）

开局或死局会自动清站立匹配 / 洗牌，尽量保证有合法步。

### 2.4 特殊块（大招）

| 条件 | 生成 | 效果 |
|------|------|------|
| 四连，或 L / T 型（横≥3 且纵≥3） | **闪光同色** | 再次进入消除时，以该格为中心半径 1 爆炸，可连锁 |
| 五连及以上 | **超级猫头鹰** | 与任意色块交换 → 清全盘该色；双猫头鹰 → 清全盘非空 |
| 两枚闪光互滑 | — | 双方激活并范围爆炸 |

优先在玩家 **换入格** 生成。部分关开局预置猫头鹰 / 闪光（`starterSpecials`）。

头顶 HUD 列出全部目标，**全部完成即通关**；步数耗尽且未完成则失败。

| 目标类型 | 玩家文案 | 当前 20 关 |
|----------|----------|------------|
| `collect` | 收集红狐/蓝兔/… | ✓ 常用 |
| `clear_ice` | 清除冰块 | ✓ |
| `collect_gems` | 收集粉球 | ✓ |
| `clear_cloud` | 清除棉花 | ✓ 第 10 关 |

## 4. 障碍与机制

### 4.1 冰块

- 贴在格子上，不随块下落；消除打到该格则碎一层。
- **`under`（默认）**：动物在冰上可滑动。
- **`encase`（冰封）**：动物冻住，不能滑，需先打碎冰。

### 4.2 棉花与粉球

- **棉花**盖住格子：不可交换 / 下落；旁边消除命中削一层，需 **两次** 清掉。
- **粉球**藏在云下：云清后再命中才计入「收集粉球」。

### 4.3 冰下伙伴（雪人 / 企鹅）

- 藏在冰下，各占多格（企鹅竖 2 格优先；雪人约 2×2）。
- 占地冰块全部打碎后才露出并收获。
- 雪人露出时会震碎周围一圈冰。

### 4.4 已实现但关卡未启用

| 机制 | 玩法要点 |
|------|----------|
| **蛋壳萌鸡** | 邻消砸壳，层数耗尽收获萌鸡 |
| **藤蔓** | 缠绕覆盖格，邻消解开；多种排布 pattern |

## 5. 通关后内容

### 5.1 剩余步数加成（MovesBonus）

通关时尚有剩余步：把剩余步转成闪光等并连环爆炸加分（类「开心消消乐」手感），播完再进粉碎。

### 5.2 粉碎奖励（CrushReward）

- 当前 **20 关全部开启**；时长约 **11～14 秒**（关卡 `crushDurationMs`）。
- 不再交换：点击格子以该格为圆心爆炸清块，继续 **+10 / 格**。
- 可看激励广告 **加时 +5 秒**。
- 时间到或盘面扫空：finale 收尾爆炸剩余可炸点（有上限）。

### 5.3 清洁模式（Cleaning）

- 结算时若本关总分 ≥ **1500**，可询问进入清洁。
- 限时 **20 秒** 点击打扫；**不计入主线总分**；本关只问一次。

### 5.4 失败复活

- 看激励视频每次 **+5 步** 回到对局。
- 运行时可反复看广告复活（不限次数）。

## 6. 道具与日常经济

开局 **不白送** 局内道具；库存上限各 **9**。按钮为空时可看广告立即补给（可反复看）。

| 道具 | 效果 | 免费来源 |
|------|------|----------|
| **锤子** | 砸一格（碰到猫头鹰/闪光有范围），不扣步 | 每日登录 +1；邀请好友通关双方各 +1 |
| **重排** | 洗牌到有合法步，不扣步 | 今日再通关满 **3** 关 +1 |
| **加步** | +5 步 | 某次通关剩余步 ≥ **6** 时当日发 1（每日一次） |

## 12. 与架构文档的差异（玩法视角）

早期 `ARCHITECTURE.md` 以 Cocos + Bomb 特殊块为主；当前实装为：

- **原生 Canvas** 单壳多模式（大厅 / 对局 / 粉碎 / 清洁 / 结算）
- 四连产出 **闪光同色**（非 Bomb）
- 已扩展冰 / 棉花 / 粉球 / 埋藏伙伴等，以及 **步数加成、清洁模式、每日与邀请**
- 本地 **20 关**；公告预告 20 关后新玩法
- 藤蔓、蛋壳、`score` / `clear_blocks` 目标、棋盘 `ring` 形状：**代码就绪，关卡表未用或未投放**
