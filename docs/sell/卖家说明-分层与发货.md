# 闲鱼分层发货说明（卖家自用 · 勿发给买家）

## 结论：原稿要处理

`docs/小游戏制作教程.md` 是**内部实装笔记**，不适合原样发出，原因：

1. 写着「本仓库 / 萌宠粉碎消 / 云函数名 / 运营后台」，像在卖你的商业工程说明书  
2. 附录指向内部文档路径，买家没有仓库会懵，有仓库等于低价拿走你交付物边界  
3. 四档价位若发同一份，高价无理由、低价又给太多  

**发货只用本目录 `docs/sell/` 下对应价位文件。**

已付款、不想带价位和推销语气：发 **`docs/sell-dist/无价格版-制作发布教程/`**（源文件 `docs/sell/无价格版-制作发布教程.md`，步骤+干货体，与 19.9 售卖版分开维护）。

## 已付款 9.9 / 19.9 怎么处理

- **9.9**：只发清单或说明已停售；**不要**主动补 99，除非对方投诉或你自愿补差。
- **19.9 已卖出**：若当时发的是「无价格版单教程 PDF」，内容约等于 99 包里的 **01 制作发布教程**，但**没有**模板、验收表、备案文案、真机手册。对方没投诉就不用动；若对方觉得货不对板（曾标原价 299），可补发 99 完整包平事。
- **新单主推 ¥99**：网盘只分享 `docs/sell-dist/99-完整包/` 这一文件夹的链接；9.9 可下架或改价 99 后做新链接。

## 改价到 99 后你要做的（ checklist ）

1. 闲鱼商品：**价格改 99**，标题去掉「19.9 / 原价 299」等容易误导的字。
2. 网盘：上传 `docs/sell-dist/99-完整包/` 整包（7 个文件 + `可复制原文` 子文件夹），生成**仅该文件夹**的分享链接。
3. 详情页：用上面「¥99 · 完整包」文案；首图可写「零基础 · AI 辅助 · 制作+广告+提审」。
4. 自动发货：粘贴 99 的网盘链接 + 提取码；发货话术用上面 **99** 那段。
5. 可选第二链接：299 旗舰包单独一个商品，避免一个链接里 99 和 299 混放被转卖。
