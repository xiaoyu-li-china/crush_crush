## 一、先避开这 3 个坑

**坑 1：名称起得随便。**
小游戏名称、备案名、游戏内标题必须完全一致。备案后再改名，等于重来一遍。注册前就把名字定死。

**坑 2：只在开发者工具里测广告。**
开发者工具对原生广告支持不完整，报错是常态。很多人以为代码写错了，改了一整天。广告验收**只以真机预览为准**。

**坑 3：激励视频只认 `isEnded` 来发奖。**
流量主后台可以设置激励的最长观看时长。如果设了 15 秒而广告片有 30 秒，玩家看够 15 秒关掉时，`isEnded` 也可能是 `false`。只认它，玩家看完了却拿不到奖励，差评马上就来。正确做法：`isEnded` 为真，**或者**观看时长已达到你后台设置的时长，都发奖。

## 二、上线路径（按顺序打勾）

### 账号

- [ ] 在微信公众平台注册小游戏，记下 AppID
- [ ] 选择休闲游戏等适合的类目，按页面提示准备材料
- [ ] 安装微信开发者工具，把开发者加进项目成员

### 工程

- [ ] 开发者工具里能完整玩通一关
- [ ] 上传设置里排除了 `node_modules`、源码、测试和文档
- [ ] 广告代码先用占位 ID 写好（流量主有用户量门槛，往往要上线后才能开通）

### 广告（公众平台 → 流量主）

小游戏广告走微信自己的流量主，不需要另接第三方广告联盟。

| 用途 | 广告类型 | 建议 |
|------|----------|------|
| 失败复活、道具补给 | 激励视频 | 奖励要明确，比如 +5 步 |
| 通关结算 | 插屏 | 每 2 关一次，间隔至少 60 秒，失败局不弹 |
| 大厅底部 | 原生模板 | 只放大厅，进关立刻隐藏 |

- [ ] 开通流量主，创建以上广告位
- [ ] 把 `adunit-…` 换进配置
- [ ] 真机测：看完有奖励，中途关掉没有奖励

### 备案与提审

- [ ] 备案名与游戏内标题一致
- [ ] 场景、玩法、系统三模块的截图互不重复
- [ ] 纯广告游戏的系统功能里不写商城、货币、VIP
- [ ] 开发者工具上传 → 公众平台提交审核
- [ ] 审核说明写清：「激励用于复活和道具，插屏在结算时展示，不看广告也能继续玩」
- [ ] 审核通过后发布

## 三、上线当天 5 分钟自测

- [ ] 正式版冷启动正常
- [ ] 看完激励有奖励，中途关掉没有
- [ ] 插屏没有连续弹
- [ ] 关掉广告回到游戏，画面正常、还能点
- [ ] 流量主后台过一段时间开始有数据

## 四、卡住了先查这里

| 现象 | 方向 |
|------|------|
| 一个广告都没有 | 没开流量主、用的是游客 AppID、没用真机测 |
| 启动插屏几乎不出 | 微信限制了启动后短时间内弹插屏（错误码 2001），要延迟几秒再弹并重试 |
| 审核因广告被拒 | 有诱导文案，或者不看广告玩不下去 |
| 审核因名称被拒 | 备案名和游戏内标题不一致 |
