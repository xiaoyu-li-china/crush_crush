# 微信小游戏：制作、挂广告、发布

竖屏 Canvas 三消示例，纯广告（IAA），无内购。按下面顺序做。

---

## 总顺序

1. 装 Node + 微信开发者工具（写代码可用 Cursor / VS Code / 网页 AI，三选一）
2. 公众平台注册小游戏，记下 AppID，名称和以后备案名、游戏内标题保持一致
3. 本地做出 `game.js`，开发者工具能跑
4. 接三消逻辑、关卡、存档
5. 广告代码写好，广告位先用 `adunit-YOUR_xxx` 占位；开通流量主后换成真 ID
6. 真机测广告（开发者工具测广告不准）
7. 备案 → 上传 → 提审 → 发布

流量主往往要上线后有用户量才能开，所以广告逻辑可以先写，ID 后换。

## 1. 要装的软件

| 必装 | 用途 |
|------|------|
| Node.js LTS | `npm install`、`npm run build` 打出 `game.js` |
| 微信开发者工具 | 预览、上传、真机扫码 |

终端执行 `node -v` 有版本号即可。

写代码（任选一种）：

- **Cursor**：打开项目文件夹，用中文让 AI 改 `src/` 里的文件
- **VS Code + AI 插件**：同上
- **ChatGPT / Claude 等网页**：复制报错和代码片段去问，改完自己贴回项目

Codex、Copilot 等也是辅助写代码，**不能代替**微信开发者工具。不必装 Cocos / Unity，本路线是 Canvas 手写逻辑。

日常循环：

```
改代码 → npm run build（或 npm run dev）→ 开发者工具点「编译」
广告 → 必须预览扫码真机
```

发给 AI 时不要贴：AppID、真实 `adunit-`、云 envId、备案主体信息。

## 2. 注册与 AppID

1. [微信公众平台](https://mp.weixin.qq.com/) 注册小游戏
2. 记录 **AppID**
3. 按类目要求准备材料（纯广告一般无内购；是否要软著等以页面为准）
4. 开发者工具里用 AppID 导入项目；测广告不要用游客号
5. 广告在公众平台 **流量主** 里创建，不走第三方 SDK

## 3. 广告位规划（写玩法前定好）

| 类型 | 场景 | 给玩家的东西 |
|------|------|----------------|
| 激励 | 失败 | +5 步 |
| 激励 | 道具空 | 补 1 个道具 |
| 激励 | 奖励关 | +5 秒 |
| 插屏 | 通关结算 | 无 |
| 插屏 | 进大厅延迟弹 | 无 |
| 原生模板 | 仅大厅底 | 无；进关必须 hide |

激励奖励写死在按钮上（+5 步），不要用「看广告抽奖」。不看广告也要能重开 / 回大厅。

---

## 4. 目录建议

```
config/           关卡、广告 ID、频控
logic/            玩法，不要写 wx.*
core/adapters/    只有这里调 wx 广告、存储
presentation/     画界面
```

换广告 ID 只改 config；调插屏间隔只改数字。

## 6. TypeScript 打包成 game.js

```bash
npm init -y
npm i -D esbuild typescript
```

`package.json` 加 `"type": "module"` 和：

```json
"scripts": {
  "build": "node scripts/build.mjs",
  "dev": "node scripts/build.mjs --watch"
}
```

`scripts/build.mjs`：

```js
import * as esbuild from 'esbuild';
const watch = process.argv.includes('--watch');
const options = {
  entryPoints: ['src/main.ts'],
  bundle: true,
  outfile: 'game.js',
  format: 'iife',
  platform: 'neutral',
  target: ['es2018'],
  sourcemap: true,
};
if (watch) {
  const ctx = await esbuild.context(options);
  await ctx.watch();
} else {
  await esbuild.build(options);
}
```

`wx` 类型报错时：装小游戏类型声明，或文件顶行 `declare const wx: any;`。

上传前确认 `packOptions.ignore` 已排除 `node_modules`、`src`、`game.js.map`，主包体积见微信当前文档（常见约 4MB 主包上限）。

## 7. 三消核心代码（8×8）

### 7.1 棋盘

```js
const ROWS = 8, COLS = 8, KINDS = 5, EMPTY = 0;
const randomKind = () => 1 + Math.floor(Math.random() * KINDS);

function createBoard() {
  const board = [];
  for (let r = 0; r < ROWS; r++) {
    board.push([]);
    for (let c = 0; c < COLS; c++) {
      let kind;
      do {
        kind = randomKind();
      } while (
        (c >= 2 && board[r][c - 1] === kind && board[r][c - 2] === kind) ||
        (r >= 2 && board[r - 1][c] === kind && board[r - 2][c] === kind)
      );
      board[r].push(kind);
    }
  }
  return board;
}
```

### 7.2 找三连

```js
function findMatches(board) {
  const hit = new Set();
  for (let r = 0; r < ROWS; r++) {
    let run = 1;
    for (let c = 1; c <= COLS; c++) {
      const same = c < COLS && board[r][c] !== EMPTY && board[r][c] === board[r][c - 1];
      if (same) run++;
      else {
        if (run >= 3) for (let k = c - run; k < c; k++) hit.add(r * COLS + k);
        run = 1;
      }
    }
  }
  for (let c = 0; c < COLS; c++) {
    let run = 1;
    for (let r = 1; r <= ROWS; r++) {
      const same = r < ROWS && board[r][c] !== EMPTY && board[r][c] === board[r - 1][c];
      if (same) run++;
      else {
        if (run >= 3) for (let k = r - run; k < r; k++) hit.add(k * COLS + c);
        run = 1;
      }
    }
  }
  return hit;
}
```

### 7.3 消除 + 下落 + 连锁

```js
function collapse(board) {
  for (let c = 0; c < COLS; c++) {
    let write = ROWS - 1;
    for (let r = ROWS - 1; r >= 0; r--) {
      if (board[r][c] !== EMPTY) {
        board[write][c] = board[r][c];
        if (write !== r) board[r][c] = EMPTY;
        write--;
      }
    }
    for (let r = write; r >= 0; r--) board[r][c] = randomKind();
  }
}

function resolve(board) {
  let cleared = 0;
  for (;;) {
    const hit = findMatches(board);
    if (hit.size === 0) return cleared;
    hit.forEach((i) => { board[Math.floor(i / COLS)][i % COLS] = EMPTY; });
    cleared += hit.size;
    collapse(board);
  }
}
```

### 7.4 交换（非法不扣步）

```js
const state = { board: createBoard(), movesLeft: 20, score: 0 };

function trySwap(r1, c1, r2, c2) {
  if (Math.abs(r1 - r2) + Math.abs(c1 - c2) !== 1) return false;
  const b = state.board;
  [b[r1][c1], b[r2][c2]] = [b[r2][c2], b[r1][c1]];
  if (findMatches(b).size === 0) {
    [b[r1][c1], b[r2][c2]] = [b[r2][c2], b[r1][c1]];
    return false;
  }
  state.movesLeft--;
  state.score += resolve(b) * 10;
  return true;
}
```

触摸转格子（`info` 来自 `wx.getSystemInfoSync()`）：

```js
const cell = Math.floor(Math.min(info.windowWidth, info.windowHeight) * 0.9 / COLS);
const boardLeft = (info.windowWidth - cell * COLS) / 2;
const boardTop = 160;

function hitCell(x, y) {
  const c = Math.floor((x - boardLeft) / cell);
  const r = Math.floor((y - boardTop) / cell);
  return r >= 0 && r < ROWS && c >= 0 && c < COLS ? { r, c } : null;
}
```

## 8. 流量主广告

### 8.1 后台建位

流量主里创建：激励 1～2 个、插屏 1 个、原生模板 1 个。复制 `adunit-…`。

配置示例（换成你的 ID）：

```json
{
  "rewarded_revive":       { "adUnitId": "adunit-YOUR_REWARD_1" },
  "rewarded_crush_extend": { "adUnitId": "adunit-YOUR_REWARD_2", "extraMs": 5000 },
  "interstitial_settle":   { "adUnitId": "adunit-YOUR_INTERSTITIAL", "everyNLevels": 2, "cooldownSeconds": 60 },
  "banner_lobby":          { "adUnitId": "adunit-YOUR_CUSTOM_BANNER", "enabled": true }
}
```

`YOUR_` / `TODO_` 占位时不要 `create*Ad`，避免开发阶段刷错。

### 8.2 接口

- 激励：`wx.createRewardedVideoAd`
- 插屏：`wx.createInterstitialAd`
- 大厅横幅：`wx.createCustomAd`

每个 placement **只 create 一次**。UI 只调 `show()`，返回四种：`completed` / `skipped` / `error` / `not_ready`。**只有 completed 发奖**。show 完再 load 下一条。

### 8.3 激励何时算看完

关闭回调有 `isEnded`。流量主后台若设「最长激励 15 秒」，片长 30 秒时，看满 15 秒关，`isEnded` 也可能是 false。

做法：`isEnded === true`，**或** 从 show 到 close 已超过 14 秒（比后台设的值略短），则发奖。秒数要和后台一致。

### 8.4 插屏

参考值：通关且 `levelId % 2 === 0`，距上次插屏 ≥ 60 秒；**失败结算不弹**。

启动插屏：大厅先渲染，**延迟 2～3 秒**再 show。失败 errCode **2001** → 隔 2～3 秒重试，总等待约 45 秒，进关就停。2002 表示两次插屏太近，加大冷却。

### 8.5 横幅

仅大厅 show；进关立刻 hide。`onLoad` 里若已进关也要 hide（防迟到上屏）。

### 8.6 真机验收

- [ ] 激励看完有奖励，中途关无奖励
- [ ] 插屏按隔关 + 冷却
- [ ] 横幅进关消失
- [ ] 关广告后画面能点、别黑屏；关广告瞬间别误触棋盘（关后约 0.8s 禁点）
- [ ] 1004 无填充时提示即可，别卡 loading

开发者工具里 Banner 报错常见，以真机为准。

审核别做：假关闭按钮、不看广告过不了关、按钮写的奖励和实际不一致。

## 10. 提审发布

上传前：

- [ ] 正式 AppID，最新 build
- [ ] 无 `YOUR_` 广告占位
- [ ] 广告真机过一遍
- [ ] 图标、简介、分享图、隐私指引
- [ ] 备案状态 OK
- [ ] 主包体积 OK

步骤：开发者工具 **上传** → 公众平台 **提交审核** → 通过后 **发布**。

审核说明可写：激励用于失败复活和道具；插屏在通关结算；不看广告可重试回大厅。

发布后正式版再扫一遍广告和存档。

## 11. 上线后

- 收益异常：查流量主广告位是否封/关
- 留存掉、插屏还密：改成每 3 关 + 加长冷却
- 卡关多：先降难度再加广告

## 12. 现象对照

| 现象 | 处理 |
|------|------|
| 白屏 | 没 build 或启动报错，真机开调试 |
| 改代码无效 | 重新 build + 开发者工具编译 |
| 工具里广告报错 | 换真机 |
| 看完不发奖 | 别只认 isEnded，加观看时长判断（见 8.3） |
| 启动插屏不出 | 2001，延迟 + 重试 |
| 没广告 | 未开流量主 / 游客 AppID / 未真机 |
| 审广告拒 | 去诱导，保留不看不广告的路径 |
| 审名称拒 | 三处名称统一 |

规则以微信官方最新文档为准。
