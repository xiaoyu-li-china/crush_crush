# ¥299 旗舰包 · 使用说明

99 完整包解决的是「照着做能上线」；旗舰包多解决一件事：让你的广告代码上线后长期稳定，并且知道怎么根据数据调。

## 基础部分（与 99 完整包相同）

| 文件 | 用途 |
|------|------|
| 01 制作发布教程 | 从注册到上线的完整流程和理由 |
| 02 广告配置模板（.json） | 5 处广告场景的配置，带注释 |
| 03 提审与广告验收表 | 提审前和广告上线前的逐项检查 |
| 04 备案文案模板 | 场景 / 玩法 / 系统三模块的文案 |
| 05 真机排查手册 | 广告错误码对照，关广告后黑屏、点击穿透等问题 |

## 旗舰部分

| 文件 | 用途 |
|------|------|
| 06 分层架构与广告策略 | 代码怎么组织，广告才能随时调整而不出错；前后台问题的完整处理规则 |
| 07 玩法与变现设计提纲 | 动手前把广告位和玩法放在一张表上规划；起步数值和上线第一周该看的指标 |
| 08 广告适配关键代码片段 | 统一广告接口、发奖判定、启动插屏重试、横幅防迟到、前台闸门、关广告后的恢复 |
| 09 答疑说明 | 1 次文字答疑，7 天内有效 |

`可复制原文` 文件夹里是备案文案模板和代码片段的原始文件。**复制代码请用这里的文件**，从 PDF 里复制容易带进多余的空格和换行。

## 建议阅读顺序

1. 先读 01，了解全流程
2. 规划阶段读 07，把表填完
3. 写代码前读 06，再对照 08 改造进你的项目
4. 提审前用 03，备案用 04
5. 遇到问题先查 05，解决不了再按 09 的格式提问

---

不含：卖家游戏的完整工程、无限次修改、代办提审和备案。
