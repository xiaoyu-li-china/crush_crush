# 提审前检查表 + 广告真机验收表

建议复制到备忘录，每次发版前从头勾一遍。所有广告项必须在**真机**上验，开发者工具的结果不算数。

---

## A. 账号与工程

- [ ] 使用正式 AppID，不是游客号
- [ ] 游戏内标题、公众平台名称、备案名三处一致
- [ ] 已用最新代码重新构建入口文件
- [ ] 上传忽略列表正确，主包体积合格
- [ ] 图标、加载图、分享图、简介已配置
- [ ] 隐私保护指引和授权弹窗已配置
- [ ] 类目所需材料已通过

## B. 广告配置

- [ ] 流量主已开通
- [ ] 激励、插屏、横幅（按需）已创建
- [ ] 配置里没有残留 `TODO_` / `YOUR_` 占位
- [ ] 流量主后台的激励最长观看时长，和代码里的发奖时长阈值一致

## C. 激励视频

**复活**

- [ ] 失败时能看到复活入口
- [ ] 看完后得到约定奖励（例如 +5 步），数值和按钮文案一致
- [ ] 看到一半关掉，没有奖励
- [ ] 没有广告时（错误码 1004）提示友好，界面不卡在「加载中」

**道具补给 / 奖励关加时**

- [ ] 看完发奖，中途关掉不发
- [ ] 连续看两次，每次只发一份奖励（没有重复发放）

## D. 插屏

**结算插屏**

- [ ] 只在满足「每 N 关」的通关结算时出现
- [ ] 冷却时间内不会再弹
- [ ] 失败的结算不弹

**启动插屏（如果开启）**

- [ ] 大厅先画出来、可以操作，延迟后才弹
- [ ] 遇到 2001 会自动重试，最终能弹出来
- [ ] 进入关卡后不再弹启动插屏

## E. 大厅横幅

- [ ] 大厅底部能看到横幅，不遮挡按钮
- [ ] 进入关卡后横幅消失
- [ ] 快速「进大厅 → 立刻进关卡」，横幅也不会迟到出现在关卡里
- [ ] 横幅出现时大厅没有黑屏

## F. 关闭广告之后

每类广告各测一次：

- [ ] 画面正常，没有黑屏或停住
- [ ] 能正常点击操作
- [ ] 关闭广告的那次点击没有穿透到棋盘上
- [ ] 背景音乐恢复（未静音的情况下）
- [ ] 看广告时切到别的 App，再切回来，游戏仍然正常

## G. 审核说明（可直接修改使用）

> 本游戏为休闲闯关游戏，无内购。激励视频用于失败复活、道具补给和奖励关加时，奖励内容在按钮上明确标注；插屏在通关结算和进入大厅时展示；大厅底部展示横幅广告，关卡内不展示横幅。玩家不观看广告也可以重试关卡或返回大厅。游戏内无诱导点击、无虚假关闭按钮。

## H. 发布后 30 分钟内

- [ ] 用正式版扫码冷启动
- [ ] 再走一遍激励发奖
- [ ] 确认存档正常（关闭重开后进度还在）
- [ ] 流量主后台开始出现请求或曝光数据（可能有延迟）
