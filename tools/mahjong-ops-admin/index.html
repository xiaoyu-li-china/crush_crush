发布到线上

        
    
          
  1. CDN：下载 JSON 后上传到 `opsConfigUrl`，并在 `mahjong-cdn.json` 打开 enabled。
    2. 
          
  2. 云库：部署 setMahjongOps，环境变量 MAHJONG_OPS_ADMIN_TOKEN（≥8 位）。
    3. 
          
  3. HTTP 一键发布（推荐）：云开发控制台 → 云函数 setMahjongOps → 开启「HTTP 访问 / 云接入」→ 复制触发 URL 填到下方（无需固定 IP）。
    4. 
          
  4. 备用：复制「云函数参数」到开发者工具 → 云函数测试（callFunction，本仓库小游戏内也是这种方式）。
